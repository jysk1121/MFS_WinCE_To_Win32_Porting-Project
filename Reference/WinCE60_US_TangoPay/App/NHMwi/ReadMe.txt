========================================================================
		ActiveX Control DLL for Windows CE: NHMWI
========================================================================

ControlWizard has created this project for your NHMWI ActiveX Control
DLL, which contains 1 control.

This skeleton project not only demonstrates the basics of writing an
ActiveX Control, but is also a starting point for writing the specific
features of your control.

This file contains a summary of what you will find in each of the files
that make up your NHMWI ActiveX Control DLL.

NHMWI.h
	This is the main include file for the ActiveX Control DLL.  It
	includes other project-specific includes such as resource.h.

NHMWI.cpp
	This is the main source file that contains code for DLL initialization,
	termination and other bookkeeping.

NHMWI.rc
	This is a listing of the Microsoft Windows CE resources that the project
	uses.  This file can be directly edited with the Microsoft eMbedded Visual  
	C++ resource editor.

NHMWI.def
	This file contains information about the ActiveX Control DLL that
	must be provided to run with Microsoft Windows CE.

NHMWI.vcc
	This file contains information used by ClassWizard to edit existing
	classes or add new classes.  ClassWizard also uses this file to store
	information needed to generate and edit message maps and dialog data
	maps and to generate prototype member functions.

NHMWI.odl
	This file contains the Object Description Language source code for the
	type library of your control.

/////////////////////////////////////////////////////////////////////////////
NHMWI control:

NHMWICtl.h
	This file contains the declaration of the CNHMWICtrl C++ class.

NHMWICtl.cpp
	This file contains the implementation of the CNHMWICtrl C++ class.

NHMWIPpg.h
	This file contains the declaration of the CNHMWIPropPage C++ class.

NHMWIPpg.cpp
	This file contains the implementation of the CNHMWIPropPage C++ class.

NHMWICtl.bmp
	This file contains a bitmap that a container will use to represent the
	CNHMWICtrl control when it appears on a tool palette.  This bitmap
	is included by the main resource file NHMWI.rc.

/////////////////////////////////////////////////////////////////////////////
Other standard files:

stdafx.h, stdafx.cpp
	These files are used to build a precompiled header (PCH) file
	named stdafx.pch and a precompiled types (PCT) file named stdafx.obj.

resource.h
	This is the standard header file, which defines new resource IDs.
	The Microsoft eMbedded Visual C++ resource editor reads and updates 
	this file.
